## Overview

> **Note:** this overview is a temporary README generated by AI (Claude) and has not yet been reviewed by the author.

MirrorCalibration provides Julia tools for calibrating deformable mirrors from interferometric measurements: loading and saving mirror responses and interferograms, recording interferograms for series of control voltages through a hardware interface, processing them into phase responses, and preparing calibrated control voltages. It builds on PhaseFromInterferograms, PhaseUtils, PhasePlots and EllipseGeometry.
